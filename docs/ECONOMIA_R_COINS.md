# Sistema de Economía: R Coins

**Documento Oficial de Reglas del Programa de Lealtad Ramgos**

## 1. Definición y Valor Base
* **Nombre de la moneda:** R Coin (reemplaza a los "Puntos" / "Puntos Ramgos").
* **Valor nominal de canje:** 1,000 R Coin = $1 USD.
  *(Esto significa que 1 R Coin equivale a $0.001 USD para futuras recompensas).*

## 2. Ganancia por Compras
* **Tasa de conversión base:** Por cada $1 USD gastado = 5 R Coin.

**Ejemplos de Compras:**
| Compra | R Coin ganados | Valor equivalente de canje |
|--------|----------------|----------------------------|
| $1     | 5 R Coin       | $0.005                     |
| $5     | 25 R Coin      | $0.025                     |
| $10    | 50 R Coin      | $0.05                      |
| $20    | 100 R Coin     | $0.10                      |
| $50    | 250 R Coin     | $0.25                      |
| $100   | 500 R Coin     | $0.50                      |

## 3. Sistema de Referidos

Este modelo incentiva tanto el registro completo como la primera compra, evitando cuentas falsas.

**A. Registro Completo (KYC)**
Cuando una persona invitada completa su registro con:
* Nombre de usuario
* Teléfono
* Correo electrónico
* Verificación de identidad (KYC, si aplica)
* Tarjeta de débito o crédito registrada

**Recompensa:** El usuario que invitó recibe **500 R Coin**.
> **⚠️ REGLA CRÍTICA:** Estos 500 R Coin se *suman/registran* en el sistema, pero **SOLO se pueden hacer válidos/reclamar DESPUÉS de que el referido realice su primera compra**.

**B. Primera Compra**
Cuando el usuario referido realiza su primera compra:
* El **nuevo usuario** recibe **2,000 R Coin** como bono de bienvenida.
* El **usuario que invitó** recibe **1,000 R Coin** adicionales.

**Resumen de Referidos:**
| Acción | Nuevo Usuario | Usuario que Invita |
|--------|---------------|--------------------|
| Completa registro (KYC+tarjeta) | — | 500 R Coin (bloqueados hasta compra) |
| Realiza primera compra | 2,000 R Coin | 1,000 R Coin |
| **TOTAL MÁXIMO** | **2,000 R Coin** | **1,500 R Coin** |

## 4. Otras Acciones Comunitarias
* **Reseñas y etiquetas:** 5 R Coin por cada acción.
